# Coding agents

Coding agents use adder the way scripts do: every command that runs prints one JSON object with `--json`, problems have stable codes, and each generator describes its inputs with a JSON Schema. An agent that follows the steps below adds code the way the repository's people do, and never edits a generated file by hand.

## The loop

1. **Find the generators:** `adder list --json` lists every generator, with its description.
2. **Read one:** `adder describe <generator> --json` gives its inputs, the values its scans allow now, and `inputSchema`, a JSON Schema for the inputs.
3. **Preview:** `adder new <generator> --inputs - --dry-run --json`, with the inputs as a JSON object on standard input, lists the files it would create and update, or the problems with the inputs, without writing anything.
4. **Run:** the same command without `--dry-run` creates the files, updates the derived ones, and returns the generator's message, such as what to write next.
5. **Keep derived files current:** after changing code by hand, `adder derive` updates the files that depend on it, and `adder check` exits 3 when any is out of date.
6. **Change generated code at its source:** a file whose header says `Code generated by adder ... DO NOT EDIT.` is rewritten on the next derive. `adder explain <file> --json` names the template and output it comes from, which is what to change instead.

Warnings, such as the use of something deprecated, come in `warnings` beside `problems`, and say what to use instead.

## An AGENTS.md section

Copy this into a repository's `AGENTS.md`, or the file its agents read, and adjust the generator names:

```markdown
## Code generation with adder

This repository generates code with adder (`go tool adder`). Its generators and derived files are declared in
`adder.yaml`.

- To add a component, use a generator instead of writing the files by hand. List them with
  `go tool adder list --json`, read one with `go tool adder describe <generator> --json`, and preview with
  `go tool adder new <generator> --inputs - --dry-run --json` before running it without `--dry-run`.
- Never edit a file marked `Code generated by adder ... DO NOT EDIT.`. Run `go tool adder explain <file>` to find
  its template, and change that instead.
- After changing code that a derived file depends on, run `go tool adder derive`, and commit the result with the
  change. `go tool adder check` must pass before committing.
- Fix every warning adder reports about something deprecated, as it says.
```
